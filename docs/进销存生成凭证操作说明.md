# 进销存生成凭证 · 操作流程说明

> 适用版本：2026-10-07 起（含「进销存凭证设置」「辅助核算严格对应」「一键自动预设」）
> 适用模块：采购、销售、库存、应收应付、生产、委外

---

## 一、整体流程

```
 一次性准备                                   日常操作
┌──────────────────────────────┐   ┌───────────────────────────────────────────────┐
│ ① 会计科目建到末级             │   │ ⑤ 录入单据 → ⑥ 审核 → ⑦ 生成凭证               │
│ ② 科目挂好辅助核算（客户/供应商）│ → │        ↓ 辅助核算对不上？→ 弹窗：自动新建 / 去设置 │
│ ③ 进销存凭证设置（一键自动预设）  │   │ ⑧ 总账：凭证审核 → 记账                         │
│ ④ 往来单位 ↔ 辅助项目 对应      │   └───────────────────────────────────────────────┘
└──────────────────────────────┘
```

**一句话**：先在「进销存凭证设置」里点一次「一键自动预设」并保存、把往来单位对应好；之后每张单据「审核 → 生成凭证」，凭证进入总账按正常流程审核、记账。

---

## 二、一次性准备

### ① 会计科目建到末级

**入口**：基础资料 → 财务档案 → 会计科目

- 生成凭证只能记到**末级科目**（没有下级的科目）。有下级的科目不能直接记账，否则余额表会丢数。
- 至少要有这些科目（名称不必一字不差，系统按编码和名称识别）：

| 用途 | 常见科目 |
|---|---|
| 存货 | 原材料、库存商品（自制半成品可选） |
| 往来 | 应收账款、应付账款 |
| 收入成本 | 主营业务收入、主营业务成本 |
| 税金 | 应交税费—应交增值税—进项税额 / 销项税额 |
| 生产 | 生产成本、制造费用、应付职工薪酬（有生产 / 委外业务时） |
| 其他出入库 | 待处理财产损溢（或你想用的对方科目） |
| 收付款 | 库存现金、银行存款下的各个账户（勾选「现金科目 / 银行科目」） |

### ② 科目挂辅助核算（需要按客户 / 供应商看账时）

**入口**：基础资料 → 会计科目 → 编辑科目 → 勾选「辅助核算」，选择类别（如「客户」「供应商」或「往来单位」）

- 应收账款挂「客户」、应付账款挂「供应商」是最常见的做法。
- **科目挂了哪些辅助核算，生成凭证时就会严格按单据去找对应的辅助项目**；科目没挂的不填。
- 辅助项目（具体的客户、供应商）在 财务总账 → 辅助核算 → 核算项目 里维护；也可以留给第 ④ 步自动新建。

### ③ 进销存凭证设置（推荐用「一键自动预设」）

**入口**：基础资料 → 业务凭证设置 → **进销存凭证设置**（需要「供应链参数」权限 `scm:param`）

页面左侧分步导航：

| 步骤 | 作用 |
|---|---|
| 预设结果 | 点「一键自动预设」后出现，列出所有建议 |
| ① 对方科目 | 生成凭证用的 10 个科目 |
| ② 来源与匹配规则 | 辅助核算从单据哪个字段取值；往来单位与辅助项目怎么比对 |
| ③ 往来单位对应 | 每个客户 / 供应商对应到哪个总账辅助项目 |
| ④ 部门 / 业务员对应 | 单据上的部门、业务员对应到哪个辅助项目 |
| ⑤ 结算账户检查 | 收付款单用到的现金 / 银行科目是否还能用 |

**操作步骤：**

1. 点右上角 **「一键自动预设」** → 确认。
2. 自动切到 **「预设结果」**，三张表列出「原值 → 预设为（末级）→ 原因」：
   - **对方科目**：已配置且是末级的不动；未配置、配成上级科目、科目不存在的，预设到最底层末级。
   - **物料存货科目**：为空或非末级的，按物料类型预设——原辅材料 → 原材料，半成品 → 自制半成品（没有就用库存商品），成品 → 库存商品。
   - **往来单位应收 / 应付**：客户补应收、供应商补应付，为空或非末级的预设到末级。
   - 同时：匹配规则恢复「名称完全一致」，辅助核算取值来源恢复自动识别。
3. **逐行核对**。物料、往来单位可以取消勾选不想改的行；标红的是「本账套找不到合适科目」，需要先到会计科目补建。
   - ⚠ 「制造费用」这类没有明确对应末级的，系统取第一个末级（如「修理费」），请务必看一眼，不对就在「① 对方科目」里手工改。
4. 点 **「保存设置」**。不想要可以点「撤销预设」。
5. 回到 **「② 来源与匹配规则」** 确认：
   - **匹配规则**（默认「名称完全一致」）：
     - 名称完全一致：往来单位名称与辅助项目名称一字不差
     - 编号完全一致：往来单位编号与辅助项目编码相同
     - 编号优先，名称兜底 / 名称优先，编号兜底
   - **取值来源**：「客户 / 供应商 / 往来单位」类 → 往来单位；「部门」→ 单据部门；「个人 / 人员」→ 业务员；项目、现金流量等 → 不填。
   - 若某类别「涉及科目」不为空、来源却是「不填」，会标红——生成凭证会被拦截。

### ④ 往来单位 ↔ 总账辅助项目对应

**入口**：进销存凭证设置 → ③ 往来单位对应（部门 / 业务员在 ④）

列表按状态筛选：

| 状态 | 含义 | 怎么处理 |
|---|---|---|
| 已对应 | 已找到唯一对应项目（标签显示：名称一致 / 编号一致 / 手工指定 / 已确认 / 自动新建） | 不用处理 |
| 待确认（有近似建议） | 完全一致找不到，但有很像的，如「德赛电池科技」≈「德赛电池科技有限公司」 | 核对后点 **「采纳建议」**，或顶部 **「批量采纳近似建议」** |
| 未匹配 | 总账里没有对应项目 | 点 **「新建辅助项」**（按往来单位的编号 + 名称新建），或 **「为未匹配项批量新建辅助项」**；也可 **「手工指定」** 选一个已有项目 |

- 近似建议**必须人工确认才生效**，系统不会自动采用。
- 手工指定 / 已确认 / 自动新建的对应关系**优先于**自动匹配；点「清除指定」可恢复自动匹配。
- 同名项目有多个时显示「对应到多个同名 / 同编号项目」，只能手工指定。
- 自动新建不成功的常见原因：编码已被别的项目占用、已有同名项目、类别有必填扩展字段——按提示手工指定或到核算项目里手工建。

## 三、日常操作：单据 → 审核 → 生成凭证

### ⑤ 录入单据

在对应菜单录单（采购入库、销售发货、收款单……），往来单位、仓库、物料、数量、单价、税率照常填写。
- 科目挂了「部门」辅助的，单据上要填**部门**；挂了「个人」辅助的，要填**业务员**。
- 收款单 / 付款单要选**结算账户**（现金或银行末级科目）。

### ⑥ 审核

单据保存后点 **「审核」**。只有**已审核**的单据才能生成凭证。

### ⑦ 生成凭证（四个入口，效果相同）

| 入口 | 操作 |
|---|---|
| **财务总账 → 日常业务 → 业务凭证**（推荐） | 业务凭证中心 →「进销存单据」：默认列出全部待生成的已审核单据，勾选后 **「生成凭证」**。**逐张执行，一张失败不影响其他**，顶部显示成功 / 失败及原因；辅助核算对不上的汇总成一次提示（自动新建并重试 / 去设置页）。也可在这里删除凭证后重新生成。出纳流水、固定资产凭证在同一页面的另外两个页签处理 |
| 单据详情页 | 顶部工具栏 **「生成凭证」**（已审核且未生成凭证时才显示） |
| 单据列表 · 单张 | 操作列的 **「凭」** 按钮 |
| 单据列表 · 批量 | 勾选多张 → 工具栏 **「生成凭证」**（要求全部已审核且都没生成过；一张不成功则整批不生成，提示哪一张、什么原因） |

成功后提示「已生成凭证 0XX」，单据上的「生成凭证」按钮消失。

**生成规则：**
- 凭证日期 = 单据日期，期间 = 单据所在月；凭证号取该期间下一个号。
- 凭证状态为**未审核**，摘要为「单据号 + 物料名 / 备注」，凭证备注「供应链单据 XXX」。
- 同一科目的多行明细合并成一条分录。
- 外币单据：分录金额折成本位币，往来 / 收入 / 税额分录同时带原币金额和汇率。
- 1 分钱以内的分摊尾差自动落到金额最大的分录，保证借贷平衡。

### 被拦截时怎么办（辅助核算对应不上）

科目挂了辅助核算，而单据的往来单位 / 部门 / 业务员在总账里对应不上时，**凭证不会生成**，弹出提示：

> 辅助核算对应不上：往来单位「ASUP9 浏览器测试供应商」在「供应商」中找不到……

- **「自动新建辅助项并重试」**：按往来单位的编号与名称新建总账辅助项目，并自动重新生成凭证（推荐，适合新单位）。
- **「去设置页手工指定」**：跳到进销存凭证设置的对应行，可采纳近似建议或手工指定，处理完回到单据再点「生成凭证」。

其他拦截原因：

| 提示 | 原因 | 处理 |
|---|---|---|
| 科目 1122 的「客户」辅助核算未设置取值来源 | 来源设成了「不填」 | 设置页 ② 改为「往来单位」 |
| 要取单据的部门，但单据未填 | 科目挂了部门辅助，单据没填部门 | 反审核单据补填部门 → 审核 → 生成 |
| 对应到多个项目，无法唯一确定 | 总账里有重名项目 | 设置页手工指定 |

### ⑧ 总账审核、记账

**入口**：财务总账 → 凭证处理 → 审核记账

进销存生成的凭证与手工凭证一样：审核 → 记账，之后在明细账、辅助明细账、余额表中可查（按客户 / 供应商的辅助账同样有数）。

## 四、各类单据生成的分录

> 「存货」= 物料档案的存货科目（未配时按物料类型取末级）；「应收 / 应付」= 往来单位档案的应收 / 应付科目，未配用设置页的全局科目。其余科目均取「进销存凭证设置 → 对方科目」。

| 单据 | 借方 | 贷方 |
|---|---|---|
| 采购入库 | 存货（不含税金额）、进项税额 | 应付账款（价税合计） |
| 采购退货 | 应付账款 | 存货、进项税额（红字方向反过来） |
| 销售发货 | 应收账款（价税合计）；主营业务成本（出库成本） | 主营业务收入、销项税额；存货（出库成本） |
| 销售退货 | 主营业务收入、销项税额；存货 | 应收账款；主营业务成本 |
| 采购发票（独立录入） | 存货、进项税额 | 应付账款 |
| 采购发票（由入库单下推） | 只对「发票额 − 入库额」的**差额**补一张调整凭证；**须先给来源入库单生成凭证** | |
| 销售发票（独立录入） | 应收账款 | 主营业务收入、销项税额（不结转成本） |
| 销售发票（由发货单下推） | 只对差额补调整凭证；须先给来源发货单生成凭证；金额一致则提示「无差额，无需制证」 | |
| 收款单 / 预收款单 | 结算账户（现金 / 银行） | 应收账款 |
| 付款单 / 预付款单 | 应付账款 | 结算账户 |
| 其他入库 | 存货 | 其他出入库对方科目（默认待处理财产损溢） |
| 其他出库 | 其他出入库对方科目 | 存货 |
| 领料单 / 补料单 | 生产成本 | 存货 |
| 退料单 | 存货 | 生产成本 |
| 完工入库 / 不良品入库 | 存货（成品全成本） | 生产成本（料）、应付职工薪酬（人工）、制造费用（制费） |
| 组装单 | 生产成本（子件）；存货（成品） | 存货（子件）；生产成本（成品） |
| 拆卸单 | 与组装相反 | |
| 委外发货 | 生产成本 | 存货 |
| 委外入库 | 存货（全成本）、进项税额（加工费税） | 生产成本（料）、应付账款（加工费含税） |
| 工序委外单 | 制造费用（加工费）、进项税额 | 应付账款 |

**不生成凭证的单据**：调拨单、盘点单（只在仓库间 / 账实间调整，不影响总账）；询价、订单、报价、缺料单、MRP 等计划类单据。点了会提示「无有效分录」。

## 五、凭证生成之后

| 想做的事 | 怎么做 |
|---|---|
| 查看凭证 | 财务总账 → 凭证查询，按日期或摘要中的单据号查找 |
| 修改凭证 | 未审核、未记账时可在凭证录入里修改（建议优先改单据或设置后重新生成，保持业务与账一致） |
| 重新生成凭证 | 先在 **凭证查询** 删除该凭证 → 单据自动恢复「未生成」→ 回到单据再点「生成凭证」 |
| 反审核单据 | 已生成凭证的单据不能反审核，提示「请先在凭证查询中删除关联凭证后再反审核」——先删凭证，再反审核 |
| 删除凭证 | **已记账的凭证不能删除**，需先在总账反记账 |

## 六、常见报错对照

| 报错 / 现象 | 原因 | 处理 |
|---|---|---|
| 单据未审核 | 单据还是草稿 | 先审核 |
| 已生成凭证 | 这张单据已经有凭证 | 要重做先删凭证 |
| 科目不存在：XXXX（……本账套可用：……） | 设置或档案里的科目在本账套没有 | 设置页「一键自动预设」，或到会计科目补建 |
| 科目……有下级科目，请选择末级科目 | 保存设置时选了上级科目 | 改选末级，或用一键预设 |
| 辅助核算对应不上，未生成凭证 | 见第三节「被拦截时怎么办」 | 自动新建或手工指定 |
| X年X月已结账 / 期间已结账 | 单据日期所在期间总账已结账 | 总账反结账，或调整单据日期（需反审核） |
| 本发票由来源单据下推，请先在来源单据上生成凭证 | 下推发票只做差额 | 先给入库 / 发货单生成凭证 |
| 借贷不平衡 | 单据成本或税额异常（如出库成本为 0） | 检查单据成本、税额后重试 |
| 组装/拆卸单必须指定BOM才能生成凭证 | 旧格式组装单没有成品行也没选 BOM | 补选 BOM 或改用成品行 |
| 无有效分录 | 该类单据不生成凭证，或金额 / 成本都为 0 | 确认单据类型与金额 |
| 批量生成按钮灰色 | 选中的单据有未审核或已生成过凭证的 | 只勾选「已审核、未生成」的单据 |

## 七、建议的上线检查清单

- [ ] 会计科目：存货、往来、收入成本、税金、生产相关科目都建到末级
- [ ] 应收 / 应付科目按需挂「客户 / 供应商」辅助核算
- [ ] 进销存凭证设置：一键自动预设 → 核对（特别是制造费用）→ 保存
- [ ] 来源与匹配规则：无标红项
- [ ] 往来单位对应：「未匹配 / 待确认」处理到 0（批量采纳 / 批量新建）
- [ ] 结算账户检查：全部「正常」
- [ ] 选一张采购入库、一张销售发货试生成凭证，到凭证查询核对科目与辅助核算，确认后再批量生成
