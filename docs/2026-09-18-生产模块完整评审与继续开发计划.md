## 一、结论摘要

生产模块的**成本链路已经相当完整**：工单一单多成品、BOM 版本/替代料/副联产品、领料/补料/退料/不良品、分批完工的料与人工制费 true-up、末批吸收在制、强制关单结案结转、工序委外加工费进制费、标准成本差异——这些在进销存评审两轮（FIX-203 ~ FIX-240）里已经打磨过，本轮没有再发现 P0 级成本错账。

**短板集中在「车间执行」这一侧**：

1. **报工是按「成品」而不是按「工序」计数的**——同一件成品经过 3 道工序各报一次数，第二道就被判「超报」；完工默认数也把各工序合格数加在一起。这使工艺路线形同虚设，是当前最影响使用的缺陷（P1-1）。
2. 工单**下达后不能变更**（数量 / 日期 / 用料），只能在无下游单据时反审核重做；实际生产中「追加 20 件」「换一个替代料」都做不到，只能新开工单（缺口 C-1）。
3. **没有排程与产能**：工作中心没有产能字段，工艺路线的标准工时只用来带出报工默认值，没有负荷 / 排程 / 交期推算（缺口 C-3）。
4. **执行侧报表薄**：只有「生产执行及在制结存表」与「标准成本差异」，缺工时统计、工序在制、生产日报、工单成本明细表（缺口 C-4）。
5. 列表页（生产计划 / 报工）**无筛选无分页**，数据一多即不可用（P1-6 / P1-7）。
6. 关单、报工等状态机还有几处**没有互锁**的边角（P1-2 ~ P1-5）。

建议路径：**先修状态机与报工口径（阶段 A，1 周）→ 补列表可用性与报表（阶段 B，1 周）→ 工单变更单（阶段 C1，1 周）→ 工序级执行与产能（阶段 C2，2 ~ 3 周，需决策）**。

| 2 | **完工凭证的人工 / 制费去向**：现在 PF 直接 `借库存商品 / 贷生产成本(料) + 贷应付职工薪酬(人工) + 贷制造费用(制费)`，等于把工资计提也做在完工单里。若总账另有「借生产成本-人工 / 贷应付薪酬」的月度计提，生产成本科目永远清不平 | A 维持现状（SCM 即计提口径，总账不重复计提，只做发放）；B 改为 `贷生产成本-直接人工 / 生产成本-制造费用`，总账月末按实际归集入生产成本，差额由 C-6 结转 | 由财务定；**B 是标准成本会计口径**，改动仅凭证科目映射 + C-6 |
| 3 | 齐套分析默认口径 | 独立核算 / 按优先级分配 | 页面双模式，默认「分配」 |
| 4 | 工单变更是否允许**减少到低于已领用量** | 不允许（先退料） / 允许并提示退料 | 不允许 |
| 5 | 排程深度 | 只做负荷表与交期推算 / 做自动排程（有限产能、前推后推） | 先负荷表；自动排程另立项 |
