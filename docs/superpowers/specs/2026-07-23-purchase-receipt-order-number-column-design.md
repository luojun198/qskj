# 采购入库明细显示采购订单号设计

## 目标

采购入库单（PI）明细增加只读“采购订单号”列，与销售发货单的“销售订单号”列保持一致。

## 展示规则

- 新建、编辑、查看采购入库单时均显示。
- 明细没有采购订单来源时显示 `—`。
- 单条明细来自一张采购订单时显示该订单号。
- 单条明细来自多张采购订单时去重、排序，并使用中文顿号 `、` 连接。

## 数据来源

- 已保存单据：后端从明细 `source_line_id` 和 `field_values.source_line_allocations` 收集来源行，限定来源单类型为采购订单（PO），实时返回 `purchase_order_no`。
- 新建单据：采购订单下推、反向选择源单和多来源下推时，前端直接把来源 `doc_no` 写入临时展示字段 `purchase_order_no`。
- `purchase_order_no` 仅用于接口返回和表格展示，不新增数据库字段。

## 影响范围

仅采购入库单明细展示、来源追溯和前端类型。采购订单、采购退货及销售单据行为不变，无数据库迁移。
