# 销售订单直达销售出库设计

## 目标

销售订单选择“下推 → 销售出库”后，不再进入库存处理页，直接打开可编辑的新建销售出库单。

## 数据口径

- 来源：已审核销售订单。
- 行数量：`min(未下推数量, 当前可用库存)`。
- 可用库存继续复用现有 `/scm/docs/:id/availability` 口径，包含其它已审核未发货销售订单占用。
- 无可发数量时不生成有效出库行；下推菜单本身按现有状态接口禁用入口。
- 来源单 ID、来源行 ID、客户、仓库、价格和税率继续保留，保存时沿用现有防超推校验。

## 交互

- 下推菜单的 MRP 入口不变。
- 已有销售出库草稿时，继续直接打开该草稿。
- 可生成时进入 `ScmDocNew`，携带 `doc_type=SO` 与 `source_doc_id`，由表单实时加载可发数量。
- 原库存处理全页面保留，兼容其它入口和历史流程。

## 验证

- 单元测试覆盖直达路由。
- 单元测试覆盖可发数量、零库存行过滤、来源关联、金额与税额。
- 运行前端专项测试、类型检查和生产构建。
