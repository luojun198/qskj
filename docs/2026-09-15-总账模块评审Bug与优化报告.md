## 三、优化建议

### 架构层（建议优先）
1. **统一「记账/反记账」出入口**：`applyVoucherPosting/applyVoucherUnpost` 已是权威实现，但 autoTransfer 撤销路径手写回冲 SQL 且含已废弃 fallback。删除 `autoTransfer.ts:1984-2045/2130-2191`，全部收敛到 `applyVoucherUnpost` 并补外币回冲。
2. **平衡校验单一权威 + 服务端重算**：以 `yuanToCents(amount)` 服务端重算为唯一依据（修 P0-3），并下沉为 `applyVoucherPosting` 内的最后一道闸（`checkPostingIntegrity` 当前不查平衡），杜绝手工/结转/调汇/推凭任何调用方绕过。
3. **来源（source）守卫表驱动**：把 `cashier / asset_* / fx_reval / scm` 的删除/修改/批量删除守卫做成策略表，单张与批量共用——本次发现的「单张有守卫、批量没有」正是缺乏统一策略的典型。
4. **期初口径单一出口**：`buildAccountInitBalanceExpr / buildOpeningBalanceSumExpr / buildInitBalanceSumExpr` 三套并存且各调用点自行选择，是 P0-1/P1-账簿-3/4 的温床。规定「账簿期初一律 = opening + 归属判断后的 pre_book」，`init_balance` 仅限期初录入/试算模块读取；跨年公式抽 `resolveOpeningChain(db, accountSetId, year)`（优先读本年 opening，无行时上溯上年链式累计）五处共用。
5. **结转标志化**：给 voucher_types 加 `is_closing` 标志（或 ACD 导入时打标），`@jqy`、间接法、静态现金流、账簿排除结转全部改按标志而非 `name='结转'` 字面量（一并解决 GL-09、P1-报表-6）。
6. **借 GL-07 休眠之机收敛双真值源**：`/ledger/balance`（读 `account_balances`）已无前端调用方，删除或改造为复用实时聚合口径；报表 `include_unposted` 若要支持，同样建议 `account_balances` 改凭证明细实时聚合（账簿已多处验证可行）。

### 正确性层
7. **配置去重校验**：staticReportConfig / staticCashFlowMappings 各组编码做构建期单测断言「任一编码只属于一个组」；「按名称匹配」要么实现要么删注释（P1-报表-1/2）。
8. **错误传播**：公式引擎仿 Excel 让错误在公式链传播（SUM 遇错误格报错），至少在响应聚合 error 格数量、前端给行级红点与汇总提示（P1-报表-3）。
9. **权限一致性**：间接法链路补 accountScope；凭证详情接口补 account_set_id 过滤；批量接口补权限码与逐张校验（或筛选模式先查 ID 再复用按 ID 处理器）。
10. **年结补全**：`writeNextYearInitBalances` 增加 `foreign_init_balance/qty_*` 结转（P1-凭证-5），并配专项回归测试（高风险期末路径，勿裸改）。

### 性能层
11. **报表计算会话缓存**：一次报表计算内缓存准则探测、建账日期、top_code→叶子映射、方向表，@取数函数共享，SQL 量可降 1~2 个数量级；`buildLedgerGeneralQuery` 每科目 6 个相关子查询可改 CTE pivot 一次算完；`supplementMissingParents` 循环逐条 `get()` 改一次性建 Map；`json_extract` 无法走索引，可考虑过账时把 `aux_item_id` 冗余写入 `voucher_entries`（与 P1-账簿-5 同根因，一并解决）。
12. **金额整数化**：全面启用 `*_cents` 整数列（`account_balances` 的 cents 列已存在闲置），REAL 列派生；舍入统一「分值整数化」工具函数（含负数对称处理），`balanced/cashBalanceCheck` 阈值统一 `MONEY_EPSILON`。
13. **占位符自动校验**：`buildLedgerDetailQuery/buildQuantityBalanceQuery/buildForeignBalanceQuery` 的 params 均为手工顺序 push，极易漂移。加通用测试工具：对每个 builder 断言 `match(/\?/g).length === params.length`，并让 `resolvePreBookRangeFlags` 的 4 布尔全组合跑一遍参数对齐。

### 前端体验层
14. **统一竞态防护 composable**：抽 `useRacedQuery(fn)`（请求序号 + AbortController）一次性解决 12 个页面的旧响应覆盖问题；分页事件合并去抖。
15. **导出/打印统一走分页循环**：把 `AuxDetail.vue` 的 while-loop 全量拉取抽成共享函数，消除 Detail/Chronological/CashJournal 的 1 万/10 万上限差异。
16. **大表虚拟滚动**：Detail 页 pageSize 100000 无虚拟滚动，几千行即卡顿；建议 el-table-v2 或懒加载（小计按全量计算逻辑保持）。
17. **收敛复制粘贴**：`insertMonthlySubtotals` 五处结构相同细节各异（preBook 只有 Detail 有），抽 `utils/ledgerSubtotals.ts`；`sumBalanceSides/splitBalanceToDebitCredit` 推广到 QuantityBalance/导出 builder；删除死文件 `ledger.styles.css` 与 `AuxBalance` chunked 函数、后端 `voucher.ts.fixcand`。
