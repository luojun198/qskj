## 实现目标

参照两张参考图实现“辅助项目多栏明细账”。每张图都是同一页面：

- 上半部分：以辅助类别（部门 / 项目 / 客户等）分组，下方展开成多列，列方向 = 借/贷，每个辅助项目为一栏；分录展示在该栏目下，附加日期、凭证号、摘要、对方科目（借贷对方科目）等基础列；底部展示本期合计和本年累计。
- 下半部分：选择辅助类别 + 辅助项目 + 起始/结束月份后，在表格中横向展示该辅助项目在不同“对方科目”下的借/贷发生额，附加期初/借/贷/方向/余额列。

实现两套视图其实是“同一查询的两套展示模式”：上半部分是按辅助类别分组的纵向多栏，下半部分是按对方科目横向分栏。本任务优先实现下半部分对应的“按对方科目横向分栏”视图，并把上半部分的“按辅助类别分组”纳入同页面或单独入口。

考虑到范围和现有代码，建议本次实现：

- 新增页面 `/ledger/aux-multi-column`：
  - 顶部筛选：辅助类别、辅助项目、年度、起始/结束月份、科目编码（可选）、“统计未记账凭证”、查询、导出 Excel、打印。
  - 表格基础列：日期、凭证号、摘要、对方科目、借贷合计、方向、余额。
  - 动态列：选定辅助项目后，把凭证分录中出现的对方科目（account_id 不等于当前科目所属方的对方科目）按横向分列显示；金额方向按对方科目方向记录，反向记负。
  - 期初/本月合计/本年累计行沿用现有账簿语义。
  - 支持栏目设置（对方科目动态列顺序、启用状态、打印名称）保存到 system_params。
  - 复用现有宽表、Hiprint 打印、Excel 导出能力。
  - 不复用现有 `/aux-detail` 接口，新增专用后端接口。

## 后端设计

### 1. 新增通用辅助项目多栏账查询服务

新增 `server/src/services/auxMultiColumnLedgerQuery.ts`，复用 `auxLedgerQuery.ts`、`initBalanceScope.ts` 和 `accountAuthorization.ts`。

核心职责：

- 接收 `auxCategoryId`、`auxItemIds`、`year`、`startMonth`、`endMonth`、`includeUnposted`、`accountScope` 等参数。
- 根据辅助类别找到指定辅助项目的 ID 集合：
  - 若用户未指定 `auxItemIds`，则使用该类别下所有启用项目；
  - 否则只使用指定项目。
- 沿用 `auxLedgerQuery.ts` 中 `buildAuxVoucherEntryFilter` 之类的辅助匹配逻辑（在当前服务中重写匹配，避免与原 `/aux-detail` 路径耦合），限定为单一辅助类别（多栏账先按单个类别支持，多类别横向栏目过宽暂不展开）。
- 解析每条分录：
  - `accountId` = 凭证明细分录所属的辅助项目对应科目（通常是某个被设置 `aux_item_id` 的末级科目），需在查询中先取回该分录的科目（voucher_entries.account_id）。
  - 对方科目 = 同一 voucher 中其余分录的科目，按对方科目 ID + 名称作为横向列 key。
  - 金额：根据对方科目方向与凭证明细方向一致记正、反向记负。
- 期初、本月合计、本年累计、借贷合计、贷方性质余额（按所选辅助科目方向），与增值税多栏账一致。
- 对辅助项目和对方科目做账号范围校验。

### 2. 新增后端路由

修改 `server/src/routes/ledger.ts`，增加：

- `GET /api/ledger/aux-multi-column/settings?aux_category_id=...&aux_item_ids=...`
- `PUT /api/ledger/aux-multi-column/settings`
- `GET /api/ledger/aux-multi-column`

权限统一使用 `ledger:aux`（已存在的辅助明细账权限）。

参数：

- `aux_category_id`：辅助类别 ID（必填）。
- `aux_item_ids`：可选，逗号分隔；不传则取该类别下全部启用项目。
- `year`、`start_month`、`end_month`、`include_unposted`、`account_code`（可选前缀）。

返回：

```ts
{
  main: { id, code, name, direction }, // 辅助项目对应末级科目的信息（仅展示用，不参与栏目）
  columns: [
    { key: 'counter_<id>', accountId, accountCode, accountName, side, printName, enabled, sortOrder }
  ],
  range: { year, startMonth, endMonth, startDate, endDate },
  initBalance: number,
  rows: MultiColumnLedgerRow[]
}
```

`rows` 复用 `multiColumnLedgerQuery.ts` 已有的 `MultiColumnLedgerRow` 形状（init/entry/month_total/year_total），`amounts` key 为对方科目 key。

### 3. 后端测试

- 账号范围校验；
- `ledger:aux` 权限校验；
- 栏目设置保存/读取。
