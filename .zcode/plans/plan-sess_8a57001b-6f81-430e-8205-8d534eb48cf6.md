## 任务
把 `/scm/arap-statement/print` 打印预览页改造为「润衡对帐单格式」，标题随应收/应付方向变化，明细按润衡 15 列展开（每条物料行=一行）。

## 改动范围（仅 1 个文件）
`client/src/views/scm/PartnerStatementPrint.vue`

**不改动**：查询页 `PartnerStatement.vue`、Excel 导出、后端、数据库、路由。

## 关键决策（已与你确认）
- **对方订单号** → 用已存在的 `scm_doc.contract_no`（合同号）近似展示
- **改造范围** → 只改打印预览页
- **应收应付** → 同一套 15 列模板，标题随方向变（ar=销售对账单/出库单号；ap=采购对账单/入库单号）

## 润衡样例回顾（已读取 .XLS）
15 列：`类别 | 出库单号 | 日期 | 发票种类 | 税率% | 订单编号 | 对方订单号 | 产品编号 | 产品名称 | 规格 | 单位 | 对方编号 | 数量 | 含税单价 | 金额`
- 每行 = 一条物料明细行（同一单的多条物料各占一行，单据字段重复）
- 「金额」列 = 含税金额（样例 1980 = 18000 × 0.11）
- 「日期」短格式：`26.6.15`（YY.M.D）

## 数据来源（系统现有字段已足够）
| 润衡列 | 数据来源 |
|---|---|
| 类别 | doc_type 映射：ar→{SO:销售出库, SR:销售退货, RCV:客户收款}；ap→{PI:采购入库, PR:采购退货, PAY:供应商付款, WI:委外入库} |
| 出库/入库单号 | `doc_no` |
| 日期 | `doc_date`（前端格式化为 YY.M.D） |
| 发票种类 | `doc.invoice_type`（已有列） |
| 税率% | `line.tax_rate` 优先，回退 `doc.tax_rate`（两者均已存在） |
| 订单编号 | `doc.field_values.order_no` 或 `cust_order_no`（若用户配了动态字段）；无则空 |
| 对方订单号 | `doc.contract_no`（已有列） |
| 产品编号/名称/规格/单位 | `line.item_code / item_name / spec / unit`（attachDocLines 已 join 物料档案） |
| 对方编号 | `line.ref_no`（dfbh，已有列） |
| 数量 | `line.qty` |
| 含税单价 | 折算 `(line.amount + line.tax_amount) / line.qty` |
| 金额 | 折算 `line.amount + line.tax_amount`（含税） |
| 收付款/调整单 | 无明细行时仍占一行，金额用 `increase_amount/settlement_amount/adjustment_amount` |

## 具体实现

### 1. 顶部 meta 改造
- 标题：`{{ docTitle }}`（ar→销售对账单 / ap→采购对账单）
- meta-block 两行布局：
  - 第 1 行：左=「客户名称 / 供应商名称：xxx」，右=「对账日期：YY.M.D」
  - 第 2 行：左=「对账期间：start ~ end」，右=「期初余额：xxx」
- 仍保留「打印时间」可放 meta 右侧或去掉

### 2. 主表 15 列改造
- `<thead>` 改为润衡 15 列表头
- 新增 `flatLines` computed：遍历 `detail[]`，把每个单据的 `doc.lines[]` 展平成独立行；同单字段在每行重复；无明细的单据占一行
- `<tbody>` 用 `v-for="(r, i) in flatLines"` 渲染
- `<tfoot>` 改为 colspan=12 + 数量合计 + 空 + 含税金额合计

### 3. 金额折算（前端）
```ts
const amountWithTax = (Number(l.amount) || 0) + (Number(l.tax_amount) || 0)
const priceWithTax  = qty ? amountWithTax / qty : 0
```
含税单价值保留 4 位小数（润衡样例 0.11/0.125/0.09）。

### 4. 日期短格式
```ts
function shortDate(d?: string) {
  if (!d) return ''
  const m = d.match(/^(\d{2,4})-(\d{1,2})-(\d{1,2})/)
  if (!m) return d
  const yy = m[1].length === 4 ? m[1].slice(2) : m[1]
  return `${yy}.${Number(m[2])}.${Number(m[3])}`
}
```

### 5. 期末大写 + 签字区
保留现有 `<div class="amount-cn">` + `rmbUpper(closing)`；签字区保留不变。

### 6. 跨页表头重复 CSS（润衡样例隐含要求，明细多行多页时表头每页重绘）
```css
table.lines thead { display: table-header-group; }
table.lines tr { break-inside: avoid; }
```

### 7. 方向推断
- 读取 `route.query.arap_type`，缺省时根据往来单位 `partner_type` 推断（customer→ar / supplier→ap），再不济默认 ar。
- 列名 / 类别标签随方向切换。

## 兼容性
